# AND Gate using Verilog HDL

## 📌 Overview

This project implements a **2-input AND Gate** using **Verilog HDL** and is simulated using **Xilinx Vivado**.

The purpose of this project is to understand the basic concepts of digital logic design, Verilog programming, and functional simulation.

## 🔧 Tools Used

- Verilog HDL
- Xilinx Vivado
- Behavioral Simulation

## ⚙️ AND Gate Logic

The output of an AND gate is HIGH (`1`) only when both inputs are HIGH (`1`).
